Wish Slots Gaming Platform

An original gaming platform project featuring custom 2D and 3D games, a customer website, Android application, backend services, and an administration dashboard.

Project Goals

- Build an original gaming platform.
- Develop custom 2D and 3D games.
- Create a responsive customer website.
- Develop an Android application.
- Build a secure custom backend.
- Provide an admin dashboard.
- Start with free-to-play demo credits only.

Technology Stack

Component| Technology
Website| Next.js + TypeScript
Admin Panel| Next.js
2D Game Engine| Phaser 3
3D Game Engine| Babylon.js
Android App| React Native + Expo
Backend| Node.js + NestJS
Database| PostgreSQL
Hosting| Vercel + Backend Hosting

First Game: Wish Slots

- 5 reels and 3 rows
- 10 original symbols
- 10 paylines
- Spin and stop animations
- Sound effects
- Mobile-friendly interface
- Demo credits only
- Server-generated game results

Security

Game outcomes must be generated and stored securely on the server. The client must never decide or modify game results.

Responsible Development

The initial version is strictly free-to-play. No deposits, wagering, cash prizes, or withdrawals will be enabled. Any future real-money functionality requires verified legal authorization, licensing, and compliance in every target jurisdiction.
